# Escáner de puertos en Python

Ejercicios que muestran distintas versiones de un escáner de puertos y un ejemplo relacionado con diagnóstico de red.

## Uso responsable

Úsalo únicamente en equipos propios o con autorización explícita. El escaneo de redes ajenas puede infringir políticas o leyes locales.

Los scripts usan módulos de la biblioteca estándar de Python. Proyecto educativo en progreso.
